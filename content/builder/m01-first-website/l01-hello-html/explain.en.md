Every website you visit — games, videos, your school's page — is made of **web pages**. A web page is a file written in a language called **HTML**. Your browser reads the HTML and shows it as a page.

HTML uses **tags**. A tag is a word inside angle brackets, like `<h1>`. Most tags come in pairs: an **opening tag**, and a **closing tag** with a slash.

```html
<h1>Hello, world!</h1>
```

- `<h1>` opens a big heading.
- `Hello, world!` is the text people see.
- `</h1>` closes the heading. Don't forget the `/`!

The browser doesn't show the tags themselves. It uses them to decide how your text looks. `h1` means "heading, level 1": the most important title on the page.

### Try it

Write your code in the editor, and the preview shows your page as you type. When you're ready, press **Check my code**.
