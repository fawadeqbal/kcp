---
title: 'CSS کا پہلا قدم: رنگ اور فونٹ'
summary: CSS سے اپنے صفحے کے رنگ اور فونٹ چنیں۔
---

HTML بتاتی ہے کہ صفحے پر **کیا** ہے۔ **CSS** بتاتی ہے کہ وہ **کیسا نظر آتا ہے**: رنگ، سائز، فونٹ اور بہت کچھ۔

CSS **رولز** کی شکل میں لکھی جاتی ہے۔ ایک رول کچھ عناصر چنتا ہے، پھر ان کے اسٹائل لکھتا ہے:

```css
h1 {
  color: tomato;
}
```

- `h1` **سلیکٹر** ہے: یہ ہر `h1` سرخی کو چنتا ہے۔
- `color` **پراپرٹی** ہے: وہ چیز جو آپ بدلنا چاہتے ہیں۔
- `tomato` **ویلیو** ہے۔ ہر لائن سیمی کولن `;` پر ختم ہوتی ہے۔

رنگ نام بھی ہو سکتے ہیں جیسے `tomato`، `navy` یا `gold`، یا کوڈ جیسے `#1e90ff`۔

دو اور کارآمد پراپرٹیز:

```css
body {
  background-color: lightyellow;
  font-family: Georgia, serif;
}
```

- `background-color` مواد کے پیچھے والی جگہ کو رنگ دیتی ہے۔
- `font-family` فونٹ چنتی ہے۔ کومے کے بعد ایک متبادل فونٹ لکھا جاتا ہے، اگر پہلا فونٹ دستیاب نہ ہو۔

ایڈیٹر میں آپ کی CSS **CSS** ٹیب میں لکھی جاتی ہے۔
