---
title: 'أول خطوات CSS: الألوان والخطوط'
summary: استخدم CSS لتختار ألوان صفحتك وخطوطها.
---

تحدّد HTML **ما** يوجد في الصفحة، وتحدّد **CSS** **شكله**: الألوان والأحجام والخطوط وغيرها.

تُكتب CSS على شكل **قواعد**. تختار القاعدة بعض العناصر، ثم تذكر الأنماط التي تُعطى لها:

```css
h1 {
  color: tomato;
}
```

- `h1` هو **المُحدِّد** (selector): يختار كل عناوين `h1`.
- `color` هي **الخاصية** (property): الشيء الذي تريد تغييره.
- `tomato` هي **القيمة**. كل سطر ينتهي بفاصلة منقوطة `;`.

يمكن أن تكون الألوان أسماءً مثل `tomato` و`navy` و`gold`، أو رموزًا مثل `#1e90ff`.

خاصيتان مفيدتان أخريان:

```css
body {
  background-color: lightyellow;
  font-family: Georgia, serif;
}
```

- `background-color` تلوّن المساحة خلف المحتوى.
- `font-family` تختار الخط. بعد الفاصلة يأتي خط احتياطي، في حال لم يكن الخط الأول متاحًا.

في المحرّر، تكتب CSS في تبويب **CSS**.
