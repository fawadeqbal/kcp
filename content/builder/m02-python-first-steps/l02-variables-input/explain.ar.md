**المتغيّر** اسم لقيمة، مثل صندوق عليه ملصق. تصنعه باستخدام `=`:

```python
nickname = "Rocket"
score = 10
print(nickname)
print(score + 5)
```

الاسم على اليسار والقيمة على اليمين (في الكود). بعد ذلك يصبح الاسم بديلًا عن القيمة. تتكوّن الأسماء من حروف إنجليزية وأرقام و`_`، ولا تحتوي على مسافات: `favourite_food` يصلح، أما `favourite food` فلا.

يمكنك وصل السلاسل النصية بعضها ببعض باستخدام `+`:

```python
print("Hello, " + nickname + "!")
```

### طرح الأسئلة

تتيح `input()` لبرنامجك أن يسأل سؤالًا وينتظر الإجابة. الإجابة سلسلة نصية يمكنك حفظها في متغيّر:

```python
name = input("What's your name? ")
print("Nice to meet you, " + name + "!")
```

هنا، اكتب إجاباتك في مربع **إجابات ‎input()‎** تحت المحرّر، كل إجابة في سطر، ثم اضغط **تشغيل**.

تعطيك `input()` نصًا دائمًا. لتستخدم الإجابة كرقم، ضعها داخل `int()`:

```python
age = int(input("How old are you? "))
print("Next year you'll be", age + 1)
```
