---

**ویری ایبل** کسی ویلیو کا نام ہوتا ہے، جیسے لیبل لگا ڈبہ۔ آپ اسے `=` سے بناتے ہیں:

```python
nickname = "Rocket"
score = 10
print(nickname)
print(score + 5)
```

کوڈ میں نام بائیں طرف اور ویلیو دائیں طرف ہوتی ہے۔ اس کے بعد وہ نام اس ویلیو کی جگہ کام کرتا ہے۔ ناموں میں انگریزی حروف، نمبر اور `_` ہوتے ہیں، اور اسپیس نہیں ہو سکتی: `favourite_food` ٹھیک ہے، `favourite food` نہیں۔

آپ `+` سے اسٹرنگز کو جوڑ سکتے ہیں:

```python
print("Hello, " + nickname + "!")
```

### سوال پوچھنا

`input()` سے آپ کا پروگرام سوال پوچھ کر جواب کا انتظار کر سکتا ہے۔ جواب ایک اسٹرنگ ہوتا ہے جسے آپ ویری ایبل میں رکھ سکتے ہیں:

```python
name = input("What's your name? ")
print("Nice to meet you, " + name + "!")
```

یہاں اپنے جوابات ایڈیٹر کے نیچے **‎input()‎ کے جوابات** والے خانے میں لکھیں، ہر جواب ایک لائن میں، پھر **چلائیں** دبائیں۔

`input()` ہمیشہ متن دیتا ہے۔ جواب کو نمبر کی طرح استعمال کرنے کے لیے اسے `int()` میں لپیٹیں:

```python
age = int(input("How old are you? "))
print("Next year you'll be", age + 1)
```
