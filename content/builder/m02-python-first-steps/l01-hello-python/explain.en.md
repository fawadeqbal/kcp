Web pages are made with HTML and CSS. **Programs** — games, calculators, chat bots — are written in programming languages. **Python** is one of the most popular in the world: it runs YouTube's servers, space science and lots of games, and it's easy to read.

A program is a list of instructions. Python does them one by one, from the top to the bottom. Your first instruction is `print()`: it shows a message.

```python
print("Hello, world!")
print("I'm learning Python.")
```

- `print` is the instruction.
- The brackets `( )` hold what to show.
- Text goes inside quote marks `" "`. Text in Python is called a **string**.

Numbers don't need quote marks, and `print()` can show several things at once, separated by commas:

```python
print("My age is", 11)
print(2 + 3)
```

A line that starts with `#` is a **comment**: Python skips it. Comments are notes for people who read your code.

### Try it

Write your code in the editor and press **Run**. What your program prints appears under **Output**. Python downloads the first time you open a Python lesson, so it may take a moment. When your program works, press **Check my code**.
