`print()` کی دو اور لائنیں شامل کریں، تاکہ آپ کا پروگرام آپ کے بارے میں **تین لائنیں** لکھے: آپ کو کیا پسند ہے، آپ کا پسندیدہ نمبر، آپ کا پسندیدہ کھانا…

اپنا فرضی نام (نک نیم) استعمال کریں، اصل نام کبھی نہیں۔
