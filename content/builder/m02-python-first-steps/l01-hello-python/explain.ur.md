ویب صفحات HTML اور CSS سے بنتے ہیں۔ لیکن **پروگرام** — جیسے گیمز، کیلکولیٹر اور چیٹ بوٹ — پروگرامنگ زبانوں میں لکھے جاتے ہیں۔ **پائتھن** (Python) دنیا کی مشہور ترین زبانوں میں سے ایک ہے: یوٹیوب کے سرور، خلائی سائنس اور بہت سی گیمز اسی میں چلتی ہیں، اور اسے پڑھنا آسان ہے۔

پروگرام ہدایات کی ایک فہرست ہے۔ پائتھن انہیں اوپر سے نیچے، ایک ایک کر کے چلاتا ہے۔ آپ کی پہلی ہدایت `print()` ہے: یہ ایک پیغام دکھاتی ہے۔

```python
print("Hello, world!")
print("I'm learning Python.")
```

- `print` ہدایت ہے۔
- بریکٹ `( )` کے اندر وہ چیز ہوتی ہے جو دکھانی ہے۔
- متن کوٹیشن مارکس `" "` کے اندر لکھا جاتا ہے۔ پائتھن میں متن کو **اسٹرنگ** (string) کہتے ہیں۔

نمبروں کو کوٹیشن مارکس کی ضرورت نہیں، اور `print()` کوما لگا کر کئی چیزیں ایک ساتھ دکھا سکتا ہے:

```python
print("My age is", 11)
print(2 + 3)
```

جو لائن `#` سے شروع ہو وہ **کمنٹ** ہے: پائتھن اسے چھوڑ دیتا ہے۔ کمنٹس کوڈ پڑھنے والوں کے لیے نوٹس ہوتے ہیں۔

### آزما کر دیکھیں

ایڈیٹر میں اپنا کوڈ لکھیں اور **چلائیں** دبائیں۔ آپ کا پروگرام جو لکھتا ہے وہ **نتیجہ** کے نیچے نظر آتا ہے۔ پہلی بار پائتھن کا سبق کھولنے پر پائتھن ڈاؤن لوڈ ہوتا ہے، اس لیے تھوڑا وقت لگ سکتا ہے۔ جب آپ کا پروگرام کام کرے تو **کوڈ چیک کریں** دبائیں۔
