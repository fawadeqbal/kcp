---
title: if سے فیصلے کرنا
summary: پروگرام if، elif اور else سے فیصلہ کر سکتے ہیں کہ کیا کرنا ہے۔
---

پروگرام ہر وقت فیصلے کرتے ہیں: کیا آپ گیم جیت گئے؟ کیا پاس ورڈ درست ہے؟ پائتھن میں فیصلے `if` سے شروع ہوتے ہیں:

```python
guess = int(input("Guess my number: "))
if guess == 7:
    print("You got it!")
else:
    print("Try again!")
```

- `if` ایک **شرط** چیک کرتا ہے۔ اگر وہ سچ ہو تو پائتھن اس کے نیچے والی لائنیں چلاتا ہے۔
- `else` تب چلتا ہے جب شرط سچ نہ ہو۔
- `if` اور `else` والی لائن کے آخر میں کولن `:` لگانا نہ بھولیں۔
- اندر والی لائنیں **4 اسپیس** اندر ہوتی ہیں۔ اسی سے پائتھن جانتا ہے کہ کون سی لائنیں `if` کی ہیں۔

شرطیں ویلیوز کا موازنہ کرتی ہیں:

- `a == b`: ‏a اور b برابر ہیں (دو `=` نشان!)
- `a != b`: ‏a اور b برابر نہیں
- `a > b`: ‏a، ‏b سے بڑا ہے
- `a < b`: ‏a، ‏b سے چھوٹا ہے
- `a >= b`: ‏a، ‏b سے بڑا ہے یا برابر ہے

دو سے زیادہ راستوں کے لیے `elif` ("else if") لگائیں۔ پائتھن اوپر سے چیک کرتا ہے اور صرف پہلا سچا راستہ چلاتا ہے:

```python
score = int(input("Your score: "))
if score >= 90:
    print("Amazing!")
elif score >= 50:
    print("Well done!")
else:
    print("Keep practising!")
```
