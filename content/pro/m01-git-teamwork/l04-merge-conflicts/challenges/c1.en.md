Two club members changed the page's title at the same time: one on `main`, one on the `title` branch.

1. On `main`, merge `title`. Git reports a **conflict** in `index.html`.
2. Open `index.html`, choose the title (or write a new one that mixes both), and remove the marker lines.
3. Stage the file and commit to finish the merge.
