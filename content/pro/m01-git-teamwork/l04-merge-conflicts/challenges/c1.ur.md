کلب کے دو ممبرز نے ایک ہی وقت میں صفحے کا عنوان بدلا: ایک نے `main` پر، دوسرے نے `title` برانچ پر۔

1. `main` پر `title` کو مرج کریں۔ git `index.html` میں **کنفلکٹ** بتائے گا۔
2. `index.html` کھولیں، عنوان چنیں (یا دونوں کو ملا کر نیا لکھیں)، اور نشان والی سطریں ہٹا دیں۔
3. مرج مکمل کرنے کے لیے فائل اسٹیج اور کمٹ کریں۔
