يرى git ملفاتك في ثلاثة أماكن:

- **المجلد** — ملفاتك كما هي الآن؛
- **منطقة التجهيز** (staging area) — ما سيحتويه الإيداع التالي (يضع `git add` التغييرات هنا)؛
- **الإيداعات** — النسخ التي حفظتها.

ولأنك تختار ما تجهّزه، يمكن أن يحمل كل إيداع فكرة واحدة. غيّرت الصفحة _والألوان_؟ جهّز الصفحة وأودِعها أولًا، ثم الألوان: إيداعان صغيران برسالتين واضحتين أسهل فهمًا من إيداع كبير.

```text
git status                   يعرض ما هو مُجهَّز وما هو غير مُجهَّز
git diff                     التغييرات التي لم تجهّزها بعد
git diff --staged            التغييرات المجهّزة
git restore index.html       تخلّص من تغييرات ملف (عودة إلى النسخة المجهّزة)
git restore --staged a.css   ألغِ تجهيز ملف (يبقى التغيير في المجلد)
```

انتبه مع `git restore`: التغييرات التي تتخلّص منها تضيع. ولهذا بالضبط أودِع كثيرًا.

### كيف يعمل هذا الدرس

على اليسار مجلد مشروعك: اختر ملفًا لتعدّله (تُحفظ تعديلاتك أثناء الكتابة). وعلى اليمين **الطرفية**: اكتب أمرًا واضغط **Enter**. اكتب `help` لترى كل الأوامر التي يمكنك استخدامها هنا. وعندما تظن أنك انتهيت، اضغط **تحقّق من عملي**.
