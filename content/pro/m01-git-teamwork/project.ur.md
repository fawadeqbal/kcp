ہر ٹیم پروجیکٹ ایک منصوبے سے شروع ہوتا ہے۔ اس پروجیکٹ کا **ہوم پیج** بنائیں جو آپ کسی ٹیم کے ساتھ بنانا چاہیں گے — ویسا صفحہ جو ٹیم اپنی ریپوزٹری کے شروع میں رکھتی ہے۔

## آپ کے صفحے میں یہ ہونا چاہیے

1. ہیڈنگ میں پروجیکٹ کا **نام**۔
2. ایک **پیراگراف** جو بتائے کہ یہ کیا کرتا ہے۔
3. کم از کم تین فیچرز کی **فہرست**۔
4. کم از کم تین قدموں کی **نمبر والی فہرست** (`ol`): آپ کی ٹیم مل کر کیسے کام کرتی ہے (برانچز، پُل ریکویسٹس، ریویوز)۔
5. ایک **فوٹر**، اور `style.css` میں **بیک گراؤنڈ رنگ**۔

جب ہر شرط پوری ہو جائے تو اسے شائع کریں۔ ہیکاتھون میں آپ کی ٹیم ایسے ہی صفحے سے شروع کرتی ہے!
