---
title: الفروع
summary: جرّب فكرة على فرع دون أن تكسر النسخة التي تعمل، ثم ادمجها عندما تجهز.
---

**الفرع** (branch) خطّ من الإيداعات. يبدأ كل مستودع بفرع واحد اسمه `main`: هذه هي النسخة التي تعمل. وعندما تريد تجربة شيء — وضعًا داكنًا أو صفحة جديدة — أنشئ **فرعًا جديدًا** واعمل فيه، ويبقى `main` آمنًا.

```text
git branch                     اعرض الفروع (* تشير إلى الفرع الذي أنت فيه)
git switch -c dark-mode        أنشئ فرعًا اسمه dark-mode وانتقل إليه
git switch main                عُد إلى main
git merge dark-mode            أدخِل إيداعات dark-mode في الفرع الذي أنت فيه
git branch -d dark-mode        احذف فرعًا بعد دمجه
```

عندما تنتقل بين الفروع، يغيّر git ملفات مجلدك لتطابق ذلك الفرع. لا يضيع شيء: الإيداعات ما زالت على فرعها.

**الدمج** (merge) يُدخل عمل فرع آخر. إذا لم يتغيّر `main` منذ بدأ الفرع، يحرّك git الفرع `main` إلى الأمام ببساطة ("fast-forward"). وإذا كان في الفرعين إيداعات جديدة، يصنع git **إيداع دمج** يجمعهما.

في الفريق، يعمل كل واحد على فرعه ويدمج في `main` عندما يجهز العمل — عادةً عبر **طلب سحب** (pull request)، ليطّلع عليه زميل أو مرشد أولًا. ستفعل ذلك في الهاكاثونات.

### كيف يعمل هذا الدرس

على اليسار مجلد مشروعك: اختر ملفًا لتعدّله (تُحفظ تعديلاتك أثناء الكتابة). وعلى اليمين **الطرفية**: اكتب أمرًا واضغط **Enter**. اكتب `help` لترى كل الأوامر التي يمكنك استخدامها هنا. وعندما تظن أنك انتهيت، اضغط **تحقّق من عملي**.
