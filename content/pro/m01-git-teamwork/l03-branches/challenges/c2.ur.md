ایک ساتھی نے `footer` برانچ پر فوٹر مکمل کر لیا ہے۔ یہ تیار ہے، تو اسے `main` میں لے آئیں۔

1. پہلے دیکھ بھال کریں: `git branch` برانچز کی فہرست دکھاتا ہے، اور `git log --oneline footer` فوٹر برانچ کے کمٹس دکھاتا ہے۔
2. `main` پر رہتے ہوئے `footer` برانچ مرج کریں۔
3. دیکھیں کہ `footer.html` اب آپ کے فولڈر میں ہے، اور `git log --oneline` چلائیں۔
