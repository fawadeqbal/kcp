صفحہ پہلے سے ایک کمٹ میں ہے۔ اب اسے بدلیں اور دوسرا ورژن محفوظ کریں۔

1. `index.html` کھولیں اور اپنے مشاغل کی فہرست شامل کریں (`ul` اور `li`)۔
2. `git status` اور `git diff` چلائیں: git بالکل وہی دکھاتا ہے جو آپ نے بدلا۔
3. اسے اسٹیج اور کمٹ کریں۔ پھر `git log --oneline` دیکھیں: دو کمٹس!
