في هذا المجلد صفحة ويب، لكن git لا يعتني بها بعد.

1. ابدأ مستودعًا بالأمر `git init`.
2. نفّذ `git status` لترى الصفحة تنتظر كملف **غير متتبَّع** (untracked).
3. جهّزها وأودِعها مع رسالة.
