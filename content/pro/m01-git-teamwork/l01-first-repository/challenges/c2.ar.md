الصفحة موجودة في إيداع واحد. الآن غيّرها واحفظ نسخة ثانية.

1. افتح `index.html` وأضف قائمة بهواياتك (`ul` و`li`).
2. نفّذ `git status` و`git diff`: يعرض git ما غيّرته بالضبط.
3. جهّزه وأودِعه. ثم انظر إلى `git log --oneline`: إيداعان!
