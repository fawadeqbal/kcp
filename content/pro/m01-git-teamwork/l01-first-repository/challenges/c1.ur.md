اس فولڈر میں ایک ویب صفحہ ہے، لیکن git ابھی اس کا خیال نہیں رکھ رہا۔

1. `git init` سے ریپوزٹری شروع کریں۔
2. `git status` چلائیں تاکہ صفحہ **untracked** (غیر ٹریک شدہ) فائل کے طور پر نظر آئے۔
3. اسے اسٹیج کریں اور ایک پیغام کے ساتھ کمٹ کریں۔
