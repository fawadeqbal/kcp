---
title: مستودعك الأول
summary: يحفظ git لقطات من مشروعك، فتستطيع دائمًا رؤية ما تغيّر والعودة إليه.
---

هل حفظت يومًا ملفات باسم `page-final.html` و`page-final-2.html` و`page-really-final.html`؟ **git** يحلّ هذه المشكلة. فهو يحتفظ بكل نسخة محفوظة من مشروعك في مكان واحد، مع ملاحظة عمّا تغيّر. ويستخدمه تقريبًا كل فريق برمجة في العالم.

المجلد الذي يعتني به git اسمه **مستودع** (repository أو "repo"). والنسخة المحفوظة اسمها **commit** (إيداع). ويتمّ الإيداع بخطوتين:

1. **جهّز** التغييرات التي تريد حفظها: `git add index.html` (أو `git add .` لكل شيء).
2. **أودِعها** برسالة قصيرة: `git commit -m "Add my home page"`.

```text
git init                        ابدأ مستودعًا هنا (مرة واحدة)
git status                      ما الذي تغيّر منذ آخر إيداع
git add index.html              جهّز ملفًا
git commit -m "Add my page"     احفظ التغييرات المجهّزة
git log --oneline               السجلّ، الأحدث أولًا
```

اكتب رسائل تقول ماذا يفعل الإيداع: "Add a footer" أو "Fix the heading colour". ستشكرك نفسك (وفريقك) لاحقًا.

### كيف يعمل هذا الدرس

على اليسار مجلد مشروعك: اختر ملفًا لتعدّله (تُحفظ تعديلاتك أثناء الكتابة). وعلى اليمين **الطرفية**: اكتب أمرًا واضغط **Enter**. اكتب `help` لترى كل الأوامر التي يمكنك استخدامها هنا. وعندما تظن أنك انتهيت، اضغط **تحقّق من عملي**.
