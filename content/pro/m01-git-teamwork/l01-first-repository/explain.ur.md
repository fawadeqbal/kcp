title: آپ کی پہلی ریپوزٹری
summary: git آپ کے پروجیکٹ کی تصویریں محفوظ کرتا ہے، تاکہ آپ ہمیشہ دیکھ سکیں کہ کیا بدلا اور واپس جا سکیں۔
---

کیا آپ نے کبھی فائلیں `page-final.html`، `page-final-2.html` اور `page-really-final.html` کے نام سے محفوظ کی ہیں؟ **git** یہ مسئلہ حل کرتا ہے۔ یہ آپ کے پروجیکٹ کا ہر محفوظ ورژن ایک جگہ رکھتا ہے، ساتھ میں ایک نوٹ کہ کیا بدلا۔ دنیا کی تقریباً ہر کوڈنگ ٹیم اسے استعمال کرتی ہے۔

جس فولڈر کا خیال git رکھتا ہے اسے **ریپوزٹری** (یا "repo") کہتے ہیں۔ محفوظ کیا گیا ورژن **کمٹ** (commit) کہلاتا ہے۔ کمٹ بنانے کے دو قدم ہیں:

1. جو تبدیلیاں محفوظ کرنی ہیں انہیں **اسٹیج** کریں: `git add index.html` (یا سب کچھ کے لیے `git add .`)۔
2. انہیں ایک مختصر پیغام کے ساتھ **کمٹ** کریں: `git commit -m "Add my home page"`۔

```text
git init                        یہاں ریپوزٹری شروع کریں (ایک بار)
git status                      آخری کمٹ کے بعد کیا بدلا
git add index.html              ایک فائل اسٹیج کریں
git commit -m "Add my page"     اسٹیج کی گئی تبدیلیاں محفوظ کریں
git log --oneline               تاریخ، نئی سب سے پہلے
```

ایسے پیغام لکھیں جو بتائیں کہ کمٹ کیا کرتا ہے: "Add a footer" یا "Fix the heading colour"۔ آگے چل کر آپ (اور آپ کی ٹیم) شکریہ ادا کریں گے۔

### یہ سبق کیسے کام کرتا ہے

بائیں طرف آپ کے پروجیکٹ کا فولڈر ہے: کسی فائل کو منتخب کر کے اس میں تبدیلی کریں (لکھتے ہی تبدیلیاں محفوظ ہو جاتی ہیں)۔ دائیں طرف **ٹرمینل** ہے: کمانڈ لکھیں اور **Enter** دبائیں۔ یہاں استعمال ہونے والی تمام کمانڈز دیکھنے کے لیے `help` لکھیں۔ جب لگے کہ کام مکمل ہو گیا ہے تو **میرا کام چیک کریں** دبائیں۔
