Bit can talk! The **say** block shows a speech bubble. Click the white box in the block to type what Bit says (keep it friendly, and never type your real name or where you live).

Until now every program started with **when ▶ Run is clicked**. That block is an **event**: something that happens and starts a script. Games use lots of events:

- **when → key is pressed** runs its blocks each time you press that arrow key.
- **when Bit touches the star** runs its blocks when Bit steps onto the star.
- **change score by 1** adds a point.

A program can have many scripts, each waiting for its own event. Put these together and you've made a game!
