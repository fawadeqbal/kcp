---
title: Bit makes decisions
summary: Use "if" so Bit looks around before it acts.
---

So far Bit has followed the same steps every time. But what if Bit doesn't know where the gems are? Bit can **check** first, with an **if** block:

- **if there is a gem here**
  - **collect the gem**

The blocks inside **if** only run when the answer is _yes_. The **if … else** block has a second part that runs when the answer is _no_.

Bit can also check the path: **if there is a path right** — move right, **else** move down. Put that inside **repeat until Bit reaches the flag**, and Bit finds its own way through the maze! A loop that keeps going until something happens is very common in games.
