بلڈر ٹریک کے ماڈیول 1 کا ایک ہی مقصد ہے: اس کے آخر تک آپ کا بچہ ایک حقیقی ذاتی ویب سائٹ بنا کر شائع کر چکا ہو۔ کسی تجربے کی ضرورت نہیں۔

## ہر سبق میں ایک خیال

ہر سبق ایک مختصر ویڈیو اور واضح وضاحت سے شروع ہوتا ہے۔ پھر آتے ہیں «خود کر کے دیکھیں» کے مراحل: براؤزر ہی میں چلنے والے کوڈ ایڈیٹر میں چھوٹے چھوٹے کام۔ سب سے پہلا کام آپ کے بچے سے ایک ہیڈنگ لکھواتا ہے:

```html
<h1>Hello, world!</h1>
```

لکھتے ہی یہ مرحلہ خودبخود جانچا جاتا ہے۔ اگر کچھ کمی ہو تو اس کی اپنی زبان میں ایک اشارہ صحیح سمت دکھاتا ہے، جواب بتائے بغیر۔

## قدم بہ قدم آگے

پورے ماڈیول میں ہر سبق ایک نیا خیال شامل کرتا ہے:

1. ہیڈنگز، پیراگراف اور فہرستیں
2. لنکس اور تصاویر
3. CSS سے رنگ اور فونٹس
4. باکسز، فاصلے اور لے آؤٹ
5. ایسے صفحات جو فون پر بھی اچھے لگیں
6. JavaScript سے پہلا بٹن جو کچھ کرتا ہے

<Callout>
  ہر مرحلے پر XP ملتے ہیں، اور روزانہ تھوڑی سی مشق مسلسل دنوں کا سلسلہ جاری رکھتی ہے۔ یہ باقاعدہ پیش
  رفت کا انعام دینے کے لیے بنایا گیا ہے، اسکرین کے سامنے لمبے گھنٹوں کا نہیں۔
</Callout>

## پروجیکٹ شائع کرنا

ماڈیول ایک پروجیکٹ پر ختم ہوتا ہے: آپ کا بچہ اپنے ذاتی صفحے کی منصوبہ بندی کرتا ہے، اسے بناتا ہے اور اپنے پورٹ فولیو میں شائع کرتا ہے۔ پورٹ فولیو نجی ہوتا ہے، اور پریمیم کے ساتھ آپ اسے لنک کے ذریعے گھر والوں سے شیئر کر سکتے ہیں۔
